# Terraform Associate Certification Notes

A summarized and reformatted collection of HashiCorp's own Terraform Associate (004) study material. Each section corresponds to a domain in the [official certification review guide](https://developer.hashicorp.com/terraform/tutorials/certification-004/associate-review-004).

## Sections

1. **Infrastructure as Code (IaC) with Terraform** — What IaC is and the problems it solves. Benefits of managing infrastructure through code instead of manual processes.
2. **Terraform fundamentals** — Terraform's purpose, multi-cloud provisioning, and how it fits into the broader HashiCorp ecosystem.
3. **Core Terraform workflow** — The write, plan, and apply cycle. Initializing a working directory and applying configuration changes.
4. **Terraform configuration** — Resource blocks, variables, outputs, provisioners, and best practices for managing sensitive data with tools like Vault.
5. **Terraform modules** — Creating and using modules, module sources, versioning, and organizing configuration for reuse.
6. **Terraform state management** — Purpose of state, remote state backends, state locking, and handling sensitive data in state files.
7. **Maintain infrastructure with Terraform** — Managing resource drift, refactoring configuration, and using imports to bring existing infrastructure under management.
8. **HCP Terraform** — Terraform Cloud and Enterprise capabilities, including remote runs, workspaces, private registries, and Sentinel policy as code.

## Purpose

These notes exist as a personal study reference for the Terraform Associate certification exam. Content is condensed and rewritten from official HashiCorp tutorials and documentation for faster review.

## Source

All material is based on and adapted from HashiCorp's official certification study guide at developer.hashicorp.com.
